RimRising - AI usage disclosure
================================

This mod was made with heavy use of generative AI. This file lists exactly where, down to the
asset. It ships inside the mod (About/AI_DISCLOSURE.txt) so the disclosure travels with every copy.
The provenance of every file was traced from the project's version history and the generation
logs kept beside the source art.

WHO DID WHAT
------------
- I (Cinergy92) directed the project: what the mod should contain, every lore call about the
  setting, balance decisions, which generated art candidates to keep or reject, and a
  play-test of my own that ran over several weeks.
- Claude (Anthropic), through Claude Code, wrote all of the code and all of the text: the C#
  assembly, every XML def and patch, and every in-game label, description, backstory, name list
  and letter. Models used across the project: Claude Opus 5, Claude Opus 5.5, Claude Fable 5 and
  Claude Fable 5.1. Claude also wrote the image-processing and drawing scripts described below.
- No text or artwork from the Red Rising novels is reproduced. All descriptions are original
  writing, and the caste sigils are original geometric marks deliberately kept unlike the
  published ones.

ART - 363 image files ship. By origin:

1. GENERATED WITH AN IMAGE MODEL, THEN CLEANED UP BY SCRIPT - 229 files
   Generated on fal (fal.ai) with OpenAI gpt-image-2 (text-to-image and its edit endpoint). Each
   result was then processed by scripts: background cut out, fitted onto a hand-measured
   silhouette so it sits on the body, colour turned into a tint mask where the item takes a caste
   colour, and given a black outline.
   - Worn armour, every facing and body type, including the Realistic Body variants:
       pulse armour (54 files), recoil armour (48), scarabSkin (24), ghost cloak (24),
       duroArmor (15), Howler pelt (16, including its inventory icon)
   - Headgear: demonHelm (8, including its inventory icon), pulse armour's built-in helm (6)
   - Weapons: razor, Reaper's razor, heirloom razor, slingBlade, pulseFist, scorcher,
       Drachenjaeger pulse cannon (7)
   - Vehicles: Drachenjaeger walker and its particle cannon and warhead rack (5),
       ripWing (3)
   - Animal: griffin, live and desiccated (6)
   - Building: clawDrill (1)
   - starShell exosuit core, hood and arm (12): gpt-image-2 plus Google nano-banana-2 (edit),
       on fal.

2. GENERATED LOCALLY WITH AN IMAGE MODEL - 3 files
   Z-Image-Turbo with a ControlNet, run in ComfyUI on my own machine.
   - The mod's preview image (the title lettering was added by script)
   - The storyteller portrait for the Board of Quality Control, large and small

3. DRAWN BY SCRIPT, NO IMAGE MODEL - 131 files
   Drawn by Python and PowerShell drawing code that Claude wrote (no generative image model was
   involved in these pixels):
   - All item icons: drugs (zoladone, mjolnir-6, nazopran, god's bread, fever cloud, swill),
       resources (helium-3, ionsteel, resFlesh, the Carveling growth vats), medical items
   - Inventory icons of pulse armour, recoil armour, duroArmor, scarabSkin and the ghost cloak,
       and the child-size armour sprites (unused in play)
   - The aegis, gravBoots and skipBoots icons
   - The pitviper and the haemanthus plant
   - Caste-mark tattoos
   - All 21 xenotype icons and the gene icons
   - Every UI glyph: ideoligion issues, memes, roles, the razor-trial ritual, abilities
   - The mod icon, the two biome textures, projectiles and effects

SOUND - 1 file
   - The razor's whip-lash sound: generated on fal with ElevenLabs Sound Effects v2.

NOT IN THIS MOD
   The optional "Cinergy's CE Patches" kept in the same source repository is a separate mod and is
   not part of this upload.

Generation logs (prompts, models and request ids) are kept with the source art in the public
project repository under Art/ - https://github.com/CInergy92/RimRising - and do not ship with the mod.
